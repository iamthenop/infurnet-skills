# Workorder reference

Tester checks accepted work against the canonical workorder template and the
validation-specific workorder requirements:

@skills/workorder-drafting/assets/workorder-template.md

@skills/workorder-drafting/references/validation-workorder.md

If the accepted workorder omits or leaves ambiguous a required template field or
validation-specific requirement, stop and report.

This reference exposes the workorder contracts. It does not load or permit the
`workorder-drafting` deliverable.
